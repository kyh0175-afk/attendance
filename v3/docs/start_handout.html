QR을 찍으면 순서대로 안내가 나와요. 3분이면 끝나요.

휴대폰 카메라로 QR을 찍어주세요

카메라 앱을 켜고 QR에 대면 링크가 떠요. 그 링크를 누르면 시작돼요.

cosmos.yubongsystem.com/v3/?start

아이폰

  1. Safari로 열어주세요
  2. 화면 아래 공유 버튼 (네모에 화살표 ↑)
  3. 내려서 홈 화면에 추가
  4. 오른쪽 위 추가
  5. 홈 화면 아이콘으로 열어서 로그인

안드로이드 · 갤럭시

  1. 크롬은 앱 설치 버튼이 바로 떠요
  2. 안 뜨면 오른쪽 위 ⋮
  3. 홈 화면에 추가 누르기
  4. 삼성 인터넷은 아래 ☰ → 현재 페이지 추가
  5. 홈 화면 아이콘으로 열어서 로그인
처음 PIN은 내 학번과 똑같아요. 로그인하면 바로 새 PIN(숫자 4~6자리)을 정하게 돼요. 남이 아는 번호(학번·생일)는 피하고, 잊어버리지 않게 기억해 주세요. 아이폰은 홈 화면에 추가한 뒤 한 번만 다시 로그인하면 계속 유지돼요.

매일 이렇게 써요

  1. 자습실 도착 → 입실 → 칠판의 입실 코드 4자리 입력
  2. 끝날 때 → 퇴실 → 선생님이 알려주는 퇴실 코드 4자리 입력
  3. 퇴실을 안 찍으면 퇴실미확인으로 남아요. 꼭 찍고 나가주세요.
