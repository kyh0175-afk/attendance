  - `config.js` — `PROGRAM_END` 상수 + `guessEndTime()`. 토요일은 13시 기준 오전/오후 추정
  - `teacher.html` — 세션 시작 화면에 **종료 시각** 입력칸(프로그램 선택 시 자동 채움, 교사가 수정 가능) + 발급 버튼 아래 자동 발급 안내
  - `teacher.js` — **20초 벽시계 비교 틱**. 긴 `setTimeout`은 전자칠판 절전에서 클램프되므로 쓰지 않음. 절전에서 깨어나도 즉시 따라잡음
  - 발동 시 `issueExit(true)` 재사용 → 코드 표시·카운트다운·마감 버튼 노출이 수동 발급과 동일
  - 교사가 먼저 수동 발급하면 자동 발급은 중단. 실패 시 20초 간격 5회까지 재시도 후 안내로 전환
  - 세션 영속에 `endAt` 포함 → 새로고침·재부팅 후에도 감시 재개. 타이머 정리 5곳

  - 새 세션 화면에 **이전 명단이 남지 않음** (P0-7)
  - 학생 대시보드 **최근 기록 맨 위에 당일 기록 즉시 반영** — 이전의 "기록을 불러오지 못했어요"는 배포 전 옛 탭의 낡은 토큰 문제였음
  - 퇴실코드 카운트다운이 **`10:00 남음`에서 시작** — 서버 `expires_at`(timestamptz) 정확히 파싱
  - 요일 표기 정확 (8.1 → 토)
- ✅ **코어 RPC 백업 + 결함 3건 수정** (`docs/core_rpc.sql` · `docs/core_rpc_fix.sql`)
  - **좀비 세션의 입실코드가 계속 유효하던 문제** — `create_v3_session`이 당일 세션만 닫아서 7/22 아우름(`9839`) 등이 열흘째 활성. `check_in`은 날짜·만료시각을 검사하지 않아 옛 코드로 입실이 가능했음. 날짜 조건 제거 + `만료시각` 검증 추가로 차단
  - **입실코드 중복 방지 부재** — DESIGN은 "서버가 보장"이라 했으나 실제로는 검사 없이 랜덤 발급. 충돌 시 학생이 다른 방 세션에 입실될 수 있었음. 재시도 루프 추가
  - **`issue_exit_code`의 `expires_at`이 `'HH24:MI'` 문자열** — 교사 화면이 파싱 실패해 클라 추정치로 폴백 중이었음(동작은 정상). timestamptz 반환으로 변경
  - 감사 결과 **`create_v3_session`/`issue_exit_code`/`finalize_session` 모두 `is_staff()` 게이트 정상** — 로그인한 학생이 남의 세션을 마감·발급할 수 없음
- ✅ **anon EXECUTE 회수** — 코어 6종(`check_in`/`check_out`/`create_v3_session`/`issue_exit_code`/`finalize_session`/`is_staff`)이 anon에 열려 있던 것을 회수. HANDOFF §7의 "PUBLIC 기본부여 + anon 멤버" 함정이 대시보드 생성 함수에만 남아 있었음. 이제 17종 전부 `anon=false`
